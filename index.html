Ethiopian Telecom Customer Service System

A C++17 console program that simulates customer data and service usage from branch level up to the national level, using arrays, functions, recursion and control statements.

Download source (.cpp) Try it online How to run

Hierarchy

Country→ Region→ City→ Branch→ Customer

Try it in your browser

Features

Interactive data entry

  • Regions, cities, branches, customers
  • Name/ID, balance, data, calls, SMS

Recursive totals

  • Customers per branch, city, region, nation
  • Total data, call and SMS usage

Top performers

  • Region with most customers
  • Highest-usage city per region
  • Largest branch per city
  • Highest balance per branch

Statistics

  • Average balance, data and calls per customer
  • Total branches nationwide

Hierarchical report

  • Customer and usage distribution
  • Branch, regional and national summaries

Input validation

  • No negative values
  • Numeric-only input, re-prompts on error
  • Division-by-zero guards

How to run

g++ -std=c++17 -Wall -o telecom ethiopian_telecom.cpp
./telecom        # on Windows: telecom.exe
